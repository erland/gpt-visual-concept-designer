# Bildfunktioner per runtime

Samtliga fem distributioner är **paketerade adaptrar**, inte verifierade bildgenereringstjänster.

- **ChatGPT Chat:** kräver bildgenerering och stöd för uppladdade bilder i värdens session.
- **OpenAI Plugin:** Skills kan aktivera metodiken; faktisk bildgenerering/analys och långlivat state kräver värdstöd.
- **Claude Projects och Claude Skills:** projektinstruktioner och kunskapsresurser är portabla; extern bildgenerering måste tillhandahållas och testas separat.
- **OpenCode:** kräver tillgängligt bildverktyg och möjlighet att läsa bilagor i den aktuella installationen.

Genererade ZIP-arkiv bevisar **inte** bildgenereringsparitet. Inget runtime-mål får lova skapade bilder när värden saknar bildgenerator.
