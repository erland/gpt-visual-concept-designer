# Exempelprojekt

Tre end-to-end-exempel visar hur GPT:n ska använda arbetsflödet:

- `guided-character/` – nybörjare från vag idé till låst karaktär och referensplan.
- `sketch-vehicle/` – en befintlig skiss utvecklas utan att kärnformen tappas.
- `environment-world/` – en världspremiss utvecklas till miljöspråk och Style Bible.

Exemplen innehåller inte färdiggenererade bilder. De demonstrerar dialoglogik, designbeslut, bildbriefar och produktionshandoff. Faktiska bilder skapas när GPT:n körs med ett bildverktyg.
