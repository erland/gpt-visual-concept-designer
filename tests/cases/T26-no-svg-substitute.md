# T26 – Ingen SVG-ersättning för konceptbild

## Prompt
Skapa en snygg, målad konceptbild av den låsta karaktären.

## Förväntat
- GPT:n anropar Image generation.
- Den använder inte Python, SVG, HTML, Canvas eller diagramverktyg.
- Resultatet är konstnärlig konceptbild, inte vektorskiss eller placeholder.

## Underkänt
GPT:n skapar eller länkar en SVG/HTML/Python-rendering som ersättning för bilden.
