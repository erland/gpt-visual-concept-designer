# T18 – Produktionshandoff till Game Graphics Creator

**Startprompt:** “Konceptet är låst. Skapa ett handoff-paket som Game Graphics Creator kan använda för sprites och porträtt.”

## Must

- Levererar koncept-ID, status, medium, syfte och auktoritativa referenser.
- Anger fasta egenskaper, tillåten variation och förbjudna förändringar.
- Anger palett, material, proportioner, kamerabehov och läsbarhetskrav.
- Skiljer designkrav från ännu obeslutade produktionsspecifikationer.
- Rekommenderar vilken ytterligare referens som saknas, om någon.
