# T27 – Bildverktyget är inte tillgängligt

## Situation
Image generation kan inte anropas.

## Förväntat
- GPT:n säger tydligt att bildverktyget inte kunde användas.
- Den erbjuder inte en SVG, diagramfil eller programmatisk illustration som ersättning.
- Den kan behålla designspecifikationen och exportera prompt endast på uttrycklig begäran.
