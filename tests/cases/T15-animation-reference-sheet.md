# T15 – Referensark för animation

**Startprompt:** “Jag har valt designen. Hjälp mig skapa ett referensark som en animatör kan använda.”

## Must

- Föreslår turnaround, proportioner, expressions, rörelse-/posebehov och relevanta detaljvyer.
- Prioriterar neutral och konsekvent presentation framför dramatisk ljussättning.
- Identifierar detaljer som kan behöva förenklas för animation.
- Skiljer referensark från hero art.
