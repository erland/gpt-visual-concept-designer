# T20 – Importera och uppdatera zip

## Prompt
Här är senaste projekt-zippen. Lägg till den nya karaktärsbeskrivningen och ge mig en uppdaterad zip.

## Förväntat
- Läser projektmanifest, bildmanifest och changelog först.
- Bevarar befintliga filer.
- Höjer versionen och dokumenterar ändringen.
- Skriver inte över originalzippen.
