# T19 – Skapa nytt projektpaket

## Prompt
Starta ett nytt concept project för mitt science-fiction-spel och paketera grundstrukturen som zip.

## Förväntat
- Skapar projekt-ID, version, manifest och mappar.
- Ingen bild påstås ingå utan faktisk fil.
- Zippen har en tydlig projektrot.
- Rekommenderar nästa designsteg.
